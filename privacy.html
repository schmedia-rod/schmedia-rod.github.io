Privacy Policy

Last updated: November 1, 2026

SmartRot ("the tool") is a private, single-user application operated by the owner of the YouTube channels "Smart Rot" and "StreamersRod" (contact: schmedia@web.de) ("the operator"). It is used exclusively by the operator to manage the operator's own YouTube channels.

1. YouTube API Services

The tool uses YouTube API Services (YouTube Data API v3 and YouTube Analytics API). By using the tool you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

2. What data is accessed

  • OAuth access token for the operator's own Google account (scopes: youtube.upload, youtube (channel branding settings of the own channel), yt-analytics.readonly).
  • Video metadata the operator creates (title, description, tags, publishing time) and the IDs of uploaded videos.
  • Aggregated statistics of the operator's own videos (views, average view percentage, likes, shares, subscribers gained). No personal data of viewers is accessed.

3. How data is used

Data is used solely to upload and schedule the operator's videos and to evaluate which of the operator's own videos perform well. Data is not sold, shared with third parties, or used for advertising.

4. Storage

All data is stored locally on the operator's computer (files config/token_*.json, logs/uploads.csv, logs/analyse_*.csv). No server or cloud database is used. API data is refreshed or deleted in accordance with the YouTube API Services Developer Policies (statistics older than 30 days are deleted or refreshed).

5. Revoking access and deleting data

  • Access can be revoked at any time via the Google security settings: https://security.google.com/settings/security/permissions.
  • Deleting the files listed in section 4 removes all stored data. On request to schmedia@web.de, all stored data is deleted within 7 days.

6. Cookies

The tool and this website do not use cookies or tracking.
